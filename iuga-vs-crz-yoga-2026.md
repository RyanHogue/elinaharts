## Fabric collections, side by side

Both brands use the same naming trick — a proprietary collection name standing in for a specific
fabric blend. Here's what each one actually publishes:

| IUGA collection | Fabric composition | Best for |
|---|---|---|
| **FlexTight** | 77% Polyester, 23% Spandex | Everyday leggings/shorts, tummy control, scrunch-butt styling |
| **PowerTight** | 69% Nylon, 31% Elastane | Higher compression, workout-focused |
| **SilkFeel** | 80–81% Polyester, 19–20% Spandex | Soft, silky, includes the plus-size line |
| **FlexDenim®** | Cotton/polyester/spandex blend (roughly 40–57% cotton) | Denim-look jeans, jeggings, shorts — not activewear |

| CRZ Yoga collection | Fabric composition | Best for |
|---|---|---|
| **Butterluxe** | 81% Polyamide, 19% Lycra | Yoga, lounging |
| **Butterlift** | 74% Polyamide, 26% Lycra | Workout, more compression |
| **Nakedfeel** | Not exactly published | Hot yoga, Pilates |
| **Feathery-Fit** | 86% Polyester, 14% Elastane | Running, cardio |
| **Pima Cotton** | 92% Pima cotton, 8% Spandex | Casual wear, real cotton feel |
| **Secretsculpt** | Same as Butterlift, no front seam | Leggings as outerwear |

**The clearest difference:** CRZ Yoga has a dedicated **real-cotton** line (Pima Cotton, 92% cotton).
IUGA has nothing equivalent for activewear — its only cotton-heavy pieces are the FlexDenim jeans and
jeggings, which are a different category of product entirely, not a soft-cotton legging or tee.
If a natural-fiber option matters to you specifically for activewear, that's a point for CRZ Yoga.

On the flip side, **IUGA is the only one of the two with a genuine denim line** — the FlexDenim
collection is real stretch-denim jeans and jean shorts, not a legging with a denim-look print (though
IUGA also sells a separate "Denim-Look" FlexTight line that IS a printed legging — worth checking
which one a listing actually is before buying if the distinction matters to you).
